# Hwaye Studio Website Concept

A responsive, single-page website concept built with vanilla HTML, CSS, and JavaScript. The visual direction and copy take inspiration from the official Hwaye Studio website (https://hwaye.studio/), with a dedicated in-development feature for Halu: The Phoenix.

## Files
- `index.html` - page structure and content
- `style.css` - responsive styling, effects, and layout
- `script.js` - mobile navigation and scroll reveal interactions

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
- The background images are temporary Unsplash placeholders. Replace them with official Hwaye Studio promotional artwork before publishing.
- Halu: The Phoenix links to its Steam store page.
- Google Fonts and remote background images require an internet connection.
